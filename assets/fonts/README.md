# Local interface fonts

These are the same families and weights already used by Corporate Cleanup. The official Latin WOFF2 subsets are served locally and embedded in the standalone game. Characters outside these subsets use the existing system fallbacks.

- Barlow Condensed: weights 500, 600, 700, 800. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- IBM Plex Mono: weights 400, 500. Source: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Both families are licensed under the SIL Open Font License 1.1. Original copyright and licence notices are included in barlowcondensed-OFL.txt and ibmplexmono-OFL.txt. The downloaded font files are unmodified.

Fetched 2026-11-04 from Google Fonts. No remote font request is required at runtime.
