# Corporate Cleanup

A browser-first, single-player survival shooter.

Play: https://leolunelove.github.io/corporate-cleanup/

Progress is saved locally in your browser. Saves on localhost do not automatically carry to this site; use Settings → Export save / Import save to transfer them.

## Controls
WASD to move, left click to shoot, right click to aim, R to reload, Shift to sprint, Space to dodge, E to interact. Touch controls are included.

## Local preview
Serve this directory using any static HTTP server, then open index.html. No server-side services or accounts are required.
